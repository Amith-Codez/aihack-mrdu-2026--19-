# assets/ · raw visual material (the optional ASSETS lane in Cowork)

- `models/` · 3D models (GLB/glTF): library downloads or AI-generated. Claude Code optimizes them into `web/public/models/`.
- `images/` · hero art, illustrations, textures generated or collected to the art direction lock in 05 §17
- `icons/`, `fonts/`, `audio/` · only if 05 §16 lists them
- `LICENSES.md` · one line per asset: file · source URL · licence (CC0 / CC-BY 4.0 / OFL / own) · credit text. The README credits come from here.

Rules: never commit an asset without a licence line. No real people's faces or brand logos you don't own. AI images never pretend to be product screenshots.
